# MOYO Client Portal
### MOYO Graduate Programme 2027 — Software Development Case Study
**Candidate:** Mahadio Tlaka  
**System:** Client Portal  
**Stack:** Angular · C# .NET 10 · Entity Framework · SQL Server · Azure

## Overview
The Client Portal is part of the Online Order Solution — a three-system platform built for MOYO's Software Development case study. It allows clients to log in, browse products, place orders, and track their order status.

## Project Structure
- `src/web` — Angular front end
- `src/backend` — C# .NET 10 API
- `database/scripts` — SQL Server database scripts

## How to Run
### Backend
```bash
cd src/backend/Api
dotnet run
```
### Frontend
```bash
cd src/web
npm install
ng serve
```
